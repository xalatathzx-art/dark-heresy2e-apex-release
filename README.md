# Dark Heresy 2E [Apex Edition]

A game system for Foundry VTT v14.

## Install

In Foundry: Game Systems → Install System, and paste this Manifest URL:

```
https://github.com/xalatathzx-art/dark-heresy2e-apex-release/releases/latest/download/system.json
```

Report problems in [Issues](https://github.com/xalatathzx-art/dark-heresy2e-apex-release/issues).
